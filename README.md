# Indonesia Pharmaceutical Industry – Financial Performance

An interactive financial dashboard analyzing the performance of publicly listed pharmaceutical companies in Indonesia.

## Key Financial Indicators
- Total Revenue
- Net Profit
- Net Profit Margin
- Year-on-Year Revenue Growth
- Financial Performance Trends

## Tools
- Tableau Public
- Microsoft Excel
- Power Query
